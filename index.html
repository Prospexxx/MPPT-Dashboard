The engineering problem

Standalone solar pumping systems degrade badly under Partial Shading Conditions (PSC): bypass diodes create multiple local maxima (LMPP) next to the global one (GMPP). Conventional P&O locks onto the nearest local peak — wasting up to 70% of harvestable energy and stalling the pump.

The solution

A modified Ćuk DC-DC converter (continuous input/output currents → less capacitor stress, longer PV life) driven by a hybrid Whale Optimization + Differential Evolution running deterministically on an ARM Cortex-M4, with dynamic slew-rate limiting and a PyQt6 dashboard for live verification.

  • Gate driving: FOD3182 high-speed optocouplers for galvanic isolation.

  • Calibration: Vin = 0.096227·ADC − 152.99 V embedded in firmware.

Enclosure & thermal

CTM-WODE algorithm architecture

Runs on an STM32F407VGT (Cortex-M4 @ 168 MHz, hardware FPU). Whale Optimization explores globally; Differential Evolution refines locally.

  • Phase 1 — Coarse scouting: 4 candidate duties (D = 0.55, 0.40, 0.25, 0.10) map the multi-peak P–V landscape.
  • Phase 2 — Local refine (DE): ±4% band around the best peak, mutation + crossover.
  • Slew-rate limiting: ΔD ≤ 0.025 per cycle — no destructive current spikes.
  • Per-duty power averaging: 3-sample accumulator prevents false peak ranking.
  • Re-tracking: re-init when P < 0.70·P_best (irradiance change).
Core/Src/mppt_algo.c — WODE local refine
/* Local refinement after WODE coarse scouting */
static void WODE_Prepare_Local_Refine(float center_duty) {
    float W = WODE_LOCAL_WIDTH; /* 0.04 (4%) */

    wode_dc[0] = center_duty;
    wode_dc[1] = center_duty - W;
    wode_dc[2] = center_duty + W;

    if (center_duty < ((WODE_DMIN + WODE_DMAX) * 0.5f)) {
        wode_dc[3] = center_duty + (2.0f * W);
    } else {
        wode_dc[3] = center_duty - (2.0f * W);
    }

    for (int i = 0; i < POP_SIZE; i++) {
        wode_dc[i] = clampf_local(wode_dc[i], WODE_DMIN, WODE_DMAX);
        wode_p[i]  = 0.0f;
    }
}
