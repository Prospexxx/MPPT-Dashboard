The Engineering Problem

Standalone solar pumping systems suffer severe power degradation and hydraulic stalling under Partial Shading Conditions (PSC). Bypass diodes across shaded modules create multiple local power peaks (LMPP) alongside the Global Maximum Power Point (GMPP). Conventional algorithms like Perturb & Observe (P&O) inevitably get trapped in the nearest local peak, wasting up to 70% of potential energy.

The Solution Delivered

Designed an end-to-end standalone MPPT solution utilizing a Modified Ćuk DC-DC converter topology that features continuous input and output currents (critical for reducing capacitor stress and extending PV module lifespan). Embedded a custom hybrid Whale Optimization Algorithm & Differential Evolution (WODE) on an ARM Cortex-M4 STM32 microcontroller with dynamic slew-rate limiting, and monitored performance through a custom PyQt6 dashboard.

CTM-WODE Algorithm Architecture

The firmware executes on an STM32F407VGT ARM Cortex-M4 microcontroller running at 168 MHz with hardware floating-point unit (FPU). The hybrid algorithm combines Whale Optimization (global exploration) and Differential Evolution (local refinement):

  • Phase 1 — Coarse Scouting: Evaluates 4 candidate duty cycles (D = 0.55, 0.40, 0.25, 0.10) to map the multi-peak P-V landscape.
  • Phase 2 — Local Refine (DE): Fine-tunes candidate duty within ±4% bandwidth of the highest peak using mutation and crossover.
  • Dynamic Slew-Rate Limiting: Duty cycle transitions are bounded to ΔD ≤ 0.025 (2.5%) per control cycle, eliminating destructive current spikes.
  • Per-Duty Power Averaging: Replaces global filter lag with 3-sample dedicated accumulator to prevent incorrect peak ranking.
  • Re-tracking Trigger: Re-initializes global search if P_actual < 0.70 · P_best (irradiance change detection).
// Core/Src/mppt_algo.c — WODE Local Refinement Snippet
/* Local refinement after WODE coarse scouting */
static void WODE_Prepare_Local_Refine(float center_duty) {
    float W = WODE_LOCAL_WIDTH; // 0.04 (4%)

    wode_dc[0] = center_duty;
    wode_dc[1] = center_duty - W;
    wode_dc[2] = center_duty + W;

    if (center_duty < ((WODE_DMIN + WODE_DMAX) * 0.5f)) {
        wode_dc[3] = center_duty + (2.0f * W);
    } else {
        wode_dc[3] = center_duty - (2.0f * W);
    }

    for (int i = 0; i < POP_SIZE; i++) {
        wode_dc[i] = clampf_local(wode_dc[i], WODE_DMIN, WODE_DMAX);
        wode_p[i]  = 0.0f;
    }
}
